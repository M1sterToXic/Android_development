# Проект "Интерфейсы"


## Структура проекта

### Файлы:

- **Movable.kt** - интерфейс Movable с базовыми свойствами и методами для движущихся объектов
    - Свойства: x, y, currentSpeed
    - Метод: move()

- **Human.kt** - базовый класс Human, реализующий интерфейс Movable
    - Представляет человека со случайным движением
    - Дополнительные свойства: name, surname, age, group_number

- **Driver.kt** - класс Driver, наследующий от Human
    - Переопределяет метод move() для движения по прямой
    - Дополнительное свойство: car

- **Main.kt** - основной файл с точкой входа программы
    - Создает объекты и управляет многопоточным выполнением
