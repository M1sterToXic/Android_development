## Практическая работа №2 — Наследование

### Формулы движения

1. **Случайное движение (`Human`):**
\[
x_{new} = x + v \cdot \cos(\varphi)
\]
\[
y_{new} = y + v \cdot \sin(\varphi)
\]

где  
- \(v\) — случайная скорость в диапазоне \([0.5 \cdot v_{base}, 1.5 \cdot v_{base}]\),  
- \(\varphi\) — случайный угол направления в диапазоне \([0, 2\pi]\).  

2. **Прямолинейное движение (`Driver`):**
\[
x_{new} = x + v
\]
\[
y_{new} = y
\]

---

### Краткое описание кода

- **Класс `Human`** — описывает человека (ФИО, возраст, скорость, координаты).  
  Метод `move()` реализует случайное движение.  

- **Класс `Driver`** — наследует `Human`.  
  Переопределяет метод `move()`, движение идёт только по оси **X**.  

- **Функция `main()`**:  
  - создаются 2–4 объекта `Human` и 1 объект `Driver`;  
  - движение выполняется параллельно через `Thread`;  
  - выводятся финальные координаты всех объектов.
